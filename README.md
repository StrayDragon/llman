## 安装

通过 git tag 分发（需要 nightly 工具链，`rust-toolchain.toml` 会自动切换）：

```bash
# 固定版本（推荐）
cargo install --git https://github.com/StrayDragon/llman --tag v0.0.72

# 最新主干
cargo install --git https://github.com/StrayDragon/llman
```
